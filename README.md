# Starfall

A tiny arcade game about dodging falling meteors and collecting stars.

## Play

Open `index.html` in a browser. No build step or dependencies are needed.

- Move with the arrow keys or WASD.
- On touch screens, use the directional pad below the playfield.
- Collect stars, avoid meteors, and try to beat your best score.

Your best score is saved in this browser using local storage.
